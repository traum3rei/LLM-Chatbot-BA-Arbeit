\chapter{Anforderungen}
\section{Anforderungsanalyse}
Es gibt fünf Punkte die laut Experteninterviews gefordert sind. 
\begin{enumerate}
    \item Der Bot soll lokal laufen aufgrund von Datenschutz
    \item Der Bot soll in einer Chatgruppe laufen, damit IT-Supportmitarbeiter eingreifen können, falls nötig
    \item Der Bot soll Unternehmensdaten verwenden
    \item Der Bot soll mit der Zeit auf neues Wissen zugreifen können
    \item Der Bot soll auf Deutsch arbeiten
\end{enumerate}
